# Mexerica — downloads

Instaladores e atualizações automáticas do **Mexerica**, um conversor de arquivos por arrastar e soltar.
Comece a arrastar um arquivo e toque **Shift** (converter), **Ctrl/⌘** (ferramentas) ou **Alt/⌃** (ações).

**[Baixar a última versão](https://github.com/raul4223/mexerica-releases/releases/latest)**

Este repositório só guarda os arquivos publicados; os apps instalados se atualizam sozinhos a partir daqui.
